## 3️⃣ Hangman Game

🔗 **Repository:**  
[CodeAlpha_HangmanGame](https://github.com/TejanshVaibhav07/CodeAlpha_HangmanGame)

The **Hangman Game** is an interactive terminal-based word-guessing game developed using Python.

A random word is selected from a predefined list, and the player attempts to identify the word by guessing letters while managing a limited number of incorrect guesses.

### Key Features

- Random word selection
- Predefined word list
- Maximum of 6 incorrect guesses
- Letter-by-letter guessing
- Duplicate-guess detection
- Input validation
- Number and symbol validation
- Game-state tracking
- Win/Lose detection
- ASCII-art Hangman stages
- Replay functionality

### Concepts Used

`Python` · `random` · `Strings` · `Loops` · `Conditions` · `Functions` · `Sets` · `Input Validation` · `Game State Management`
